# Personal Portfolio Website

My personal website: who I am, what I've built, and how to reach me.

**Live site:** [nathaniel-recto.vercel.app](https://nathaniel-recto.vercel.app/)

## About
I'm a Computer Engineering graduate from Toronto Metropolitan University (Class of 2026), focused on machine learning, computer vision and embedded systems. This site works as an interactive résumé, covering everything from a basketball shot tracker running live on an iPhone to processors written in VHDL.

## Built With
- **HTML, CSS and plain JavaScript:** no frameworks, no build step
- **Google Fonts:** Space Grotesk, Inter and JetBrains Mono
- **Inline SVG icons**
- **Vercel** for hosting (redeploys automatically on every push to `main`)

## Features
- Typing role line and a clickable photo that opens a "whoami" terminal
- Scroll-animated timeline and expandable experience cards
- Skills terminal with animated stats
- Featured project showcases plus a filterable grid of hardware, embedded and software projects
- Downloadable résumé and a contact form that opens your email app
- Works on phones and respects reduced-motion settings

## Run Locally
Open `Personal Website/index.html` in a browser, or run `python -m http.server` inside that folder and visit `localhost:8000`.
